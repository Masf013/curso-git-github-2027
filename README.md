# Curso TMW Git & GitHub 2027

Um curso para iniciantes desenvolvido pelo Téo My Why focado no aprendizado do trabalho de versionamento de arquivos de código e repositórios remotos no GitHub. Além disso, vamos trabalhar com GitFlow ao final do curso e também o Visual Studio Code. Confira tudo no Youtube.

Ele funciona registrando o histórico de alterações dos arquivos, permitindo que os programadores revertam erros e acessem versões anteriores do código. Por operar de forma descentralizada, o Git facilita o trabalho em equipe, possibilitando que múltiplos desenvolvedores colaborem simultaneamente no mesmo projeto com segurança e autonomia.
